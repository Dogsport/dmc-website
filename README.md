# DMC Homepage V4.4

## Änderungen
- Mobile Icons wurden von Emoji-/Unicode-Zeichen auf interne SVG-Icons umgestellt.
- Mobiles Menü ist vollständig linksbündig und nutzt größere Touch-Flächen.
- Dark-Hero-Typografie wurde für kleine Displays verkleinert, damit lange Wörter nicht abgeschnitten werden.
- Schnellzugriffe werden auf Mobile als 2×2-Raster statt als abgeschnittener horizontaler Slider dargestellt.
- Facebook Like/Kommentar/Teilen verwenden SVG-Icons und bleiben interaktiv.
- Originale Facebook-Bildformate bleiben erhalten.
- Vergleichsseite ist vollständig auf Deutsch, enthält keine A/B-Test-Anleitung und zeigt pro Konzept nur einen Öffnen-Button.
